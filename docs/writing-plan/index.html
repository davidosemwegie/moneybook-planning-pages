What happens to a recording

  1. Save the full transcript in Raw thoughts as the next numbered note. Notes 1–9 are now saved; the next is Note 10.
  2. Read it for ideas, examples, stories, and claims.
  3. Update the relevant topic or draft chapter in the author's voice. Add or revise its companion-workbook page when an exercise needs answer space. Keep plain-paper instructions in the book.
  4. Link the new prose back to the source note.
  5. Put factual questions in Research notes.
  6. Report which book pages changed and what still needs clarification.

If one recording covers several topics, its ideas can go in several pages. The full transcript stays together as the source.
