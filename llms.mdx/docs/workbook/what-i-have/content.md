# 1. What I have now (/docs/workbook/what-i-have)



**Workbook page 1 · Chapter 1, Step 1**

Use the [book's instructions](/docs/chapters/start-where-you-are#step-1-write-down-what-you-have-now) as you fill this in. On plain paper, copy these headings and add a line for each account or place you hold cash.

Today's date: \_\_\_\_\_

Whose money am I listing? My own / our household: \_\_\_\_\_

Use the same person or household on all four pages.

## Money I have now [#money-i-have-now]

Open your accounts and count your cash. Copy the balances you can check. If you can't find an amount, write “not sure yet.”

| Where the money is   | Balance shown / label | Available amount, if different | Date checked / things to note |
| -------------------- | --------------------- | ------------------------------ | ----------------------------- |
| Everyday account     | $                     | $                              |                               |
| Savings account      | $                     | $                              |                               |
| Money held in an app | $                     | $                              |                               |
| Cash I counted       | $                     | —                              |                               |
| Other account        | $                     | $                              |                               |

Add more lines if you need them. Use one balance per account for the total. Use the current balance if shown; otherwise use the balance you copied with its label. Don't add the available column as extra money.

Count each balance once, including money moved between your own accounts. Keep credit limits out. Put a below-zero account balance on [page 3](/docs/workbook/what-i-owe) as money owed.

**Money I have now: $\_\_\_\_\_**

Add the confirmed positive balances and cash you counted. Mark this total as **partial** if an account still needs checking.

Accounts or amounts still to check: \_\_\_\_\_

Holds, pending items, or money set aside for bills: \_\_\_\_\_

This total is not all free to spend. Keep the notes beside it.
